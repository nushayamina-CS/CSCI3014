# **Computer Vision and Robotics : OpenCV Labs**

This repository contains my **Computer Vision and Robotics laboratory assignments** completed using **Python and Google Colab**.

The assignments focus on learning the basics of image processing and computer vision using **OpenCV** and **NumPy**.

## **Assignments**

### **Lab Assignment 1 \- Basic Image Processing**

This lab covers basic operations on images, including:

* Loading and displaying images  
* Converting images to grayscale  
* Finding image dimensions  
* Checking pixel values  
* Cropping part of an image  
* Drawing shapes on images  
* Adding text to images  
* Adding borders to images  
* Creating simple images using Python

### **Lab Assignment 2 \- Image Augmentation**

This lab focuses on changing images in different ways to create new versions of them.

It covers:

* Flipping images  
* Rotating images  
* Shearing images  
* Random image transformations  
* Processing multiple images  
* Creating multiple versions of an image  
* Saving the new images  
* Creating image collages to compare the results
